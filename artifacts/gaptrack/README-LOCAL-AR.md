# تشغيل GapTrack محليًا عبر XAMPP

تظهر قاعدة `gaptrack` في phpMyAdmin لديك بالفعل. لا تستورد ملف SQL مرة أخرى ما دامت الجداول الأربعة ظاهرة.

## تجهيز الملفات

1. فك ضغط مجلد GapTrack كاملًا داخل `C:\xampp\htdocs\gaptrack`.
2. انسخ `config.local.example.php` وسمِّ النسخة `config.local.php`.
3. افتح `config.local.php` في Visual Studio Code. الإعداد الافتراضي يطابق صورة XAMPP التي أرسلتها: المضيف `127.0.0.1` والمنفذ `3308` وقاعدة `gaptrack`.
4. إذا كان لحساب MySQL `root` كلمة مرور، اكتبها في خانة `password` داخل الملف المحلي فقط. لا ترسلها لأحد ولا ترفع الملف إلى GitHub.
5. شغّل Apache وMySQL في XAMPP، ثم افتح `http://localhost/gaptrack/public/`.

إذا لم تنشئ `config.local.php` بعد، سيعمل الموقع ببيانات العرض التجريبية. عند وجود ملف الإعداد، يتصل الموقع بـ MySQL، وأي مشكلة اتصال تظهر برسالة واضحة بدل الرجوع الصامت للبيانات التجريبية.

## الجداول المستخدمة

يقرأ GapTrack الجداول `shipments` و`tracking_updates` و`coverage_gap_zones` و`alerts`. عند إضافة شحنة تجريبية يحفظ الشحنة ونقاطها وتنبيهاتها في معاملة واحدة. إضافة مناطق التغطية وحذفها يحفظان مباشرة في MySQL.

رقم التتبع `GT-0001` ونظائره يتكون تلقائيًا من رقم الشحنة، لأن ملف قاعدة البيانات الأصلي لا يحتوي على عمود لرقم التتبع.

## ملاحظات

- هذا المشروع يعرض سجلات مخزنة ومحاكاة تعليمية؛ لا يتصل بجهاز GPS حقيقي.
- إذا ظهرت رسالة خطأ من phpMyAdmin أو GapTrack، أرسل صورة الخطأ بعد إخفاء أي بيانات دخول.
- لا تضع ملف `config.local.php` داخل `public` ولا تشارك نسخة تحتوي على كلمة مرور.
